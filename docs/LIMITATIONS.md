# Limitations and Responsible Use

1. **Demo only:** no public deployment, client, live CRM, contact mailbox, transactional email, monitoring or uptime commitment.
2. **Only synthetic submissions:** the SQLite database is not encrypted; do not input real personal data. No retention automation or user deletion workflow.
3. **Anti-spam is illustrative:** honeypot and in-process rate limiter are not adequate for public production exposure, multi-worker deployments or proxy chains.
4. **Email validation is syntactic only:** email address ownership is never checked.
5. **Frontend validation is supplementary:** API validation is authoritative; abuse controls remain limited.
6. **Security headers are limited examples:** no threat model, external audit, TLS termination, auth, security certification or production hardening.
7. **Accessibility:** keyboard and responsive acceptance requires manual browser testing; focus visibility and semantic landmarks alone are not WCAG certification.
8. **No WordPress, Shopify, SEO ranking, conversion results, production scalability or commercial performance claims.**
9. **MIT applies to code and included original assets only**; publishing remains a separate human decision.
